# Learn Excel with Anshu

Creator: Anshu Singh, Satna, Madhya Pradesh, India

## Run
Double-click `index.html`. No server, login or internet needed.

## Folders
- `index.html` page shell
- `css/style.css` styles and themes
- `js/data.js` translations, curriculum, datasets, exercises
- `js/engine.js` formula parser and evaluator (no eval)
- `js/app.js` pages, animations, simulator
- `js/topics.js` topic pages and topic labs
- `js/main.js` start-up

## GitHub Pages
Push this folder to a repository, then Settings > Pages > Deploy from branch (main, root).
